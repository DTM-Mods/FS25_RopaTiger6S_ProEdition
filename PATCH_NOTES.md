# Patch notes

## 1.2.2.0

- Textures identical to the base-game Ropa machines (46 files) are now loaded from the game, so the mod is about 68 MB smaller.
- Removed three unused texture files.
- Mod icon, store icons and window tint textures saved in the formats the game expects.
- Updated for game patch 1.25.1 (descVersion 116) and added a German description.

## 1.2.1.1

- The author now shows as **DTM Mods, PropaineX** in the mod list.
- The shop description lists all three tank sizes: Normal 43, Boosted 57.5 and Extreme 63 m³.

## 1.2.1.0
- Fixed the unloading and bunker belts sometimes running forever on a server after unloading ended (tank empty, engine off or getting out).

## 1.2.0.0
- Third tank option. The tanks are now called Normal (43 m³), Boosted (57.5 m³) and Extreme (63 m³). The weight limit was raised so the Extreme tank can be filled with potatoes.
- Includes the carrot / parsnip belt fixes from 1.1.3.0.

## 1.1.3.0
- More belt fixes for carrots and parsnips, including after loading a different savegame.

## 1.1.2.0
- The RR XL 9 header now tops potatoes as well.

## 1.1.1.0
- Fixed empty-looking belts when harvesting carrots.
